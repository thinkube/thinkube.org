= Screenshot inventory
:page-type: reference

_Every capture the site uses, where it was taken, and how to take it again._

Captures are real screens of the reference cluster, taken headless at 1600×1000 CSS pixels with a device scale factor of 2, so each file is 3200×2000 pixels. They are taken with `tools/capture.mjs` in the `thinkube.org` repository, which signs in to Thinkube Identity and opens each page. A capture is retaken when the page it shows changes; the file name stays the same so the pages that include it need no edit.

== Take them again

In a terminal in Thinkube IDE, in a checkout of `thinkube.org`:

[source,bash]
----
DOMAIN_NAME=<your domain> node tools/capture.mjs out/
DOMAIN_NAME=<your domain> node tools/capture.mjs out/ control-llm-gateway   # one capture
----

The script reads the password from `ANSIBLE_BECOME_PASSWORD` in `~/.env` and signs in as `thinkube`; set `SYSTEM_USERNAME` if your user is named differently. Copy the files you want into the module that includes them.

The Tandem captures on the nine-sentences playbook were taken from the thinking space in Thinkube IDE while the walkthrough ran, with the same browser and size; they are not in the script because they depend on the state of a run.

== Diagrams

Diagrams are SVG files drawn by hand or rendered from d2 at build time through Kroki; `antora-playbook.yml` sets `kroki-fetch-diagram: true`, so the built site embeds them and needs no Kroki access at runtime.
