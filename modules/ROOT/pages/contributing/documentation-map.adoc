== Kept off the site, on purpose

* The services behind the branded names, Gitea, Harbor, ArgoCD, MLflow, Keycloak, JuiceFS, SeaweedFS, PostgreSQL, DevPI, Argo Workflows, and the optional components get no pages about their own interfaces. They appear as mechanism on xref:start-here/what-is-thinkube.adoc[What Thinkube is] and the area pages, and as entries in the xref:reference/components.adoc[components catalog].
* The platform's own uses of `thinkube.yaml`, components and repositories the platform does not deploy, are platform development and are documented for maintainers outside the site.
* A playbook is published only from a run that completed end to end on the reference cluster.
* The full list of MCP operations is what Claude Code reads at `/mcp`; the site names the ones a playbook calls.

== Adding a page

. Decide the type and copy its skeleton from xref:contributing/page-types.adoc[Page types].
. Put it in the repository of the product it describes; only the site's own pages go in `thinkube.org`.
. Add it to `modules/ROOT/nav.adoc` in `thinkube.org`, once, under its section.
. Run the playbook on the reference cluster as written. Check every fact against source and name the file in the commit.
. Build with `npx --no-install antora --fetch antora-playbook.yml`; the build must print no warnings.
