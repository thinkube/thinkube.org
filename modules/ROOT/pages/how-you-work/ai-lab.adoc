= Thinkube Notebooks
:page-type: how-to

_Open a notebook, pick or build an environment, and find the playbooks._

Thinkube Notebooks is JupyterHub, reachable from the dashboard. It shares its
workspace with Thinkube IDE: a file you save in one is the same file in the
other.

== Open it

From the thinkube-control dashboard, open Thinkube Notebooks. You are already
logged in — it uses the same identity as everything else.

== Pick an environment

Environments appear as kernels. Two are ready:

* `fine-tuning` — peft, trl, bitsandbytes, Unsloth, with the CUDA and torch
  pins set for this hardware
* `agent-dev` — LangChain, CrewAI, AG2

== Build your own

Ask Claude in Thinkube IDE:

----
› make me a venv from agent-dev and add trackio and polars
----

Or in thinkube-control, under *Jupyter Kernels*, start from a template and add
packages. Either way the environment is built for your architecture and
appears as a kernel when it finishes.

== Find the playbooks

The playbooks ship as notebooks in the workspace under `examples/`:
`research-assistant/` and `zebra-grpo/`. xref:playbooks/index.adoc[Playbooks]
describes each.

== Call a served model

In any environment where `tk_llm` is available:

[source,python]
----
from tk_llm import get_openai_client

client = get_openai_client()
response = client.chat.completions.create(
    model="Qwen/Qwen3.5-4B",
    messages=[{"role": "user", "content": "Hello"}],
)
----

The client is pre-configured for your LLM Gateway; the model name is the one
the catalogue shows.
