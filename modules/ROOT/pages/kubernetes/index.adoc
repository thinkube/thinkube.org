= Thinkube Kubernetes
:page-type: concept

_The base of the platform: unmodified upstream Kubernetes on your machines, with the services every other area stands on already installed, connected and signed in, and a control plane you drive from Claude Code._

.TL;DR
Ask Claude: "what's running?". Claude calls `list_services_minimal` and answers with every service on the base: Thinkube Identity, Thinkube Storage and JuiceFS, Thinkube Registry, Thinkube Git, Argo Workflows and ArgoCD, PostgreSQL, the GPU Operator, Thinkube IDE, Thinkube Notebooks, Thinkube Experiments and Thinkube Packages. You installed none of them one by one and you configure none of them by hand; the installer put them there and thinkube-control operates them.

== The decision

Everything a production AI service needs besides the model already exists in standard Kubernetes: an address with a certificate, a login, storage that outlives a restart, a registry, a build, a rollback, a shared GPU. Thinkube installs that standard unchanged, with kubeadm, and decides the infrastructure above it once for everyone: one sign-on, one filesystem, one registry, one database, one pipeline. The three other areas never provide any of these for themselves; they use the base. And the base is operated through thinkube-control, which exposes the same operations to its web interface and to Claude Code, so running the platform is a sentence rather than a command line.

== What it saves you

* *No cluster to assemble.* Identity, storage, registry, database, certificates and names are installed, connected and signed in before you open the first page.
* *No Kubernetes commands.* Claude Code and thinkube-control do the operating; you read state and ask for changes in a sentence.
* *No GPU arithmetic.* Each GPU is shared as slots and the platform counts memory per node, so a served model, a notebook and a fine-tune fit together or are refused before they start.
* *Nothing trapped.* The cluster is upstream Kubernetes, so what you build on it runs on any other standard cluster.

== Limits

* The base installs on Ubuntu 24.04 machines; GPU nodes need an NVIDIA GPU.
* It is built for one person: one login, one set of GPUs, no queue between users.
