= Opinions on a standard
:page-type: concept

_Where Thinkube decides for you, where it doesn't, and how to tell which is which._

Thinkube is opinionated below the application and not above it. You don't
choose your identity provider or your registry; you do choose your vector
store. The line is the same one a platform team draws inside a company:
infrastructure is decided so nobody has to think about it, and architecture
is left to the person building the thing.

== Decided for you

Thinkube Identity is Keycloak. Thinkube Registry is Harbor. The database is
PostgreSQL. Thinkube Storage is SeaweedFS. Thinkube Git is Gitea; builds and deploys are Argo
Workflows and ArgoCD. The cluster is kubeadm with Cilium. You install none of
these, configure none of them, and they're wired together before you log in.

They're decided because everything else depends on them. Of the optional
components, six need Keycloak, five need PostgreSQL, five need Harbor. That
substrate is what makes an optional component a single toggle rather than an
afternoon of provisioning three datastores and registering an OIDC client.

Each was also chosen so it can't be relicensed against you: Valkey rather
than Redis, OpenSearch rather than Elasticsearch, SeaweedFS rather than
MinIO, upstream kubeadm rather than a vendor's distribution.

== Yours to choose

Three vector stores are offered — Chroma, Qdrant, Weaviate — and none is
chosen for you. Four inference backends — vLLM, TensorRT-LLM, Ollama,
text-embeddings. Observability, annotation, messaging, search: install what
you need from the catalogue, scale it to zero when you don't.

Those are your architecture. The platform has no opinion about which vector
store suits your retrieval problem, and it would be wrong to have one.

== The standard underneath

The Kubernetes under all of this is unmodified upstream, installed by
kubeadm, and certified. Nothing is forked. So the opinions rest on a
standard, and what you build on them — a git repository, a standard image —
runs anywhere that standard runs. The opinions save you the setup; the
standard means they don't trap you.
