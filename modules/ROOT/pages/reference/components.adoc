= Components catalog
:page-type: reference

_Every component, what provides it, and whether it stays running._

.TL;DR
Ask Claude: "install Qdrant and Langfuse". Core components are always present and set up by the installer. Optional ones install with what they need and use no CPU or memory while switched off. This page is the full list, with what each provides.

Optional components are installed from Thinkube Control under *Optional Components*.
Each one has a toggle that scales it to zero.

image::cp-components.png[The Optional Components page of Thinkube Control]

== Core

The first column is the name the dashboard shows.
The second is the component behind it, the name to search for when something goes wrong.

[cols="1,1,2",options="header"]
|===
| Shown as | Component | What it does

| Thinkube Identity | Keycloak | One login across every service
| Thinkube Registry | Harbor | Container images, built here and mirrored from upstream
| Thinkube Git | Gitea | Your repositories, in-cluster
| Argo Workflows | Argo Workflows | Builds images from your repositories and runs your applications' pipelines
| ArgoCD | ArgoCD | Deploys what is in Git
| PostgreSQL | PostgreSQL | Relational storage for the platform and your apps
| Thinkube Storage | SeaweedFS | S3-compatible; models and artifacts
| JuiceFS | JuiceFS | A POSIX filesystem on SeaweedFS, shared by every area; its metadata is in PostgreSQL
| Thinkube Packages | DevPI | Private Python packages
| Thinkube Notebooks | JupyterHub | Notebooks and environments
| Thinkube Experiments | MLflow | Runs, registered models, the model registry
| GPU Operator | NVIDIA GPU Operator | Device access; four time-slice slots per GPU by default
| Thinkube IDE | code-server | VS Code in the browser; Claude Code is installed from Anthropic and used with your own account
| Control panel | Thinkube Control | The web UI and the MCP endpoint
| Cluster | kubeadm, Cilium | Unmodified upstream Kubernetes; Cilium as network and load balancer
|===
